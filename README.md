# 🎲 Ludo Warriors — 2D Ludo Game

**Ludo Warriors** is a browser-based 2D Ludo game that brings a fantasy twist to the classic board game. Instead of simply sliding between tiles, the goti characters walk step by step across the board with animated movement.

The game features fantasy-inspired warriors, dice animations, turn-based gameplay, and computer-controlled opponents.

## ✨ Features

- 🎮 Interactive 2D Ludo board with four player colors
- ⚔️ Fantasy-themed warrior characters
- 🚶 Step-by-step walking animations for game pieces
- 🎲 Animated dice rolling
- 🤖 Three computer-controlled opponents
- 🏠 Base deployment and home-lane movement
- 🎯 Opponent capture mechanics and safe squares
- 🏆 Victory detection
- 🔄 Restart functionality
- 📱 Responsive browser interface
- 🌐 No installation or external libraries required

## 🛠️ Technologies Used

- **HTML5** — Game structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Game logic, turn management and AI
- **HTML Canvas API** — Board rendering and character animations

## 🎯 Gameplay

1. Start the game in your web browser.
2. Click **Roll Dice** to roll the dice.
3. Roll a six to bring a warrior out of the base.
4. Select an eligible warrior to move it along the board.
5. Watch the warrior walk one step at a time.
6. Capture opponent warriors by landing on their positions, except on safe squares.
7. Reach the home area and try to get all four warriors home before your opponents.

## 🚀 Getting Started

### Option 1: Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/ludo-warriors.git
   ```

2. Open the project folder:

   ```bash
   cd ludo-warriors
   ```

3. Open `ludo_warriors.html` in Google Chrome, Microsoft Edge, or another modern browser.

No additional dependencies or server setup are required for the standalone HTML version.

### Option 2: Run Using VS Code

1. Open the project folder in VS Code.
2. Locate `ludo_warriors.html`.
3. Open the file in your browser.
